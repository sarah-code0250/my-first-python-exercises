# My First Python Exercises

My first Python exercises. This repository contains two simple programs created to practice basic programming concepts.

## Exercises

### 1. Discount

A simple program that calculates the cost of a purchase and applies a discount depending on the number of dozens purchased.

### 2. Parking Lot

A simple program that calculates the parking fee based on the number of hours a vehicle was parked.

## Technologies

* Python

## Purpose

This project was created as a beginner exercise to practice variables, user input, arithmetic operations, and conditional statements in Python.
